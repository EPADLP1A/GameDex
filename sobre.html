Sobre o Game Dex

Um espaço simples para descobrir, pesquisar e organizar videojogos.

O que é o Game Dex?

O Game Dex é um website de catálogo de videojogos desenvolvido como projeto de equipa. Reúne jogos de diferentes géneros e plataformas, permitindo consultar informação essencial de cada título.

O que podes fazer?

  • Pesquisar jogos pelo nome ou descrição.
  • Filtrar por género e plataforma.
  • Consultar detalhes, incluindo género, plataformas e ano de lançamento.
  • Guardar jogos numa lista de favoritos, diretamente no navegador.

Tecnologias utilizadas

O projeto foi construído com HTML para a estrutura, CSS para o design adaptável e JavaScript para a pesquisa, filtros, detalhes e favoritos.
